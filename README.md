# Readability review skill

A Claude skill that reviews a document or url against the [Readability Guidelines](https://readabilityguidelines.co.uk/) and produces an actionable response with recommendations that reference the guidelines.

**Install the skill:** [readability-review.skill](https://github.com/richhiggins/readability-review/blob/main/readability-review.skill)

**Add it to Claude:** open your [skill settings](https://claude.ai/customize/skills) and upload the file.

Experimental and unofficial – your mileage may vary 😊.
